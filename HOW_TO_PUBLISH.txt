                    دليل نشر التحديث على GitHub
                         خطوة بخطوة - بسيط وسريع
═══════════════════════════════════════════════════════════════════

📋 الخطوات المطلوبة:

┌─────────────────────────────────────────────────────────────────┐
│ 1️⃣  تحديث رقم الإصدار في الكود                                │
└─────────────────────────────────────────────────────────────────┘

افتح ملف: Services\UpdateService.cs
غير السطر:
    private const string CURRENT_VERSION = "1.0.0";
إلى:
    private const string CURRENT_VERSION = "1.0.1";


┌─────────────────────────────────────────────────────────────────┐
│ 2️⃣  استخدام السكريبت التلقائي (الطريقة السهلة)                │
└─────────────────────────────────────────────────────────────────┘

افتح PowerShell في مجلد المشروع واكتب:

    .\publish-release.ps1 -Version "1.0.1" -ReleaseNotesAr "إصلاح الأخطاء وتحسينات"

السكريبت سيقوم بـ:
✅ Build المشروع
✅ إنشاء ملف ZIP
✅ تحديث version.json
✅ فتح المجلد للملف الجاهز


┌─────────────────────────────────────────────────────────────────┐
│ 3️⃣  رفع على Git                                                │
└─────────────────────────────────────────────────────────────────┘

في PowerShell أو Git Bash:

    git add .
    git commit -m "Release v1.0.1"
    git tag v1.0.1
    git push origin main
    git push origin v1.0.1


┌─────────────────────────────────────────────────────────────────┐
│ 4️⃣  إنشاء Release على GitHub                                   │
└─────────────────────────────────────────────────────────────────┘

1. اذهب إلى:
   https://github.com/YOUR_USERNAME/SoftPos/releases/new

2. املأ البيانات:
   - Choose a tag: v1.0.1
   - Release title: SoftPos v1.0.1
   - Description: اكتب وصف التحديث

3. ارفع الملف:
   - اضغط "Attach binaries by dropping them here"
   - ارفع ملف: SoftPos-v1.0.1.zip

4. اضغط "Publish release"


┌─────────────────────────────────────────────────────────────────┐
│ 5️⃣  تحديث رابط التحميل (إذا لزم)                              │
└─────────────────────────────────────────────────────────────────┘

بعد نشر الـ Release، انسخ رابط التحميل:
https://github.com/YOUR_USERNAME/SoftPos/releases/download/v1.0.1/SoftPos-v1.0.1.zip

افتح ملف: version.json
حدث الرابط في "DownloadUrl"

ثم:
    git add version.json
    git commit -m "Update download URL"
    git push


┌─────────────────────────────────────────────────────────────────┐
│ 6️⃣  اختبار التحديث                                             │
└─────────────────────────────────────────────────────────────────┘

1. شغل البرنامج القديم (نسخة 1.0.0)
2. اذهب لصفحة التحديثات
3. يجب أن يظهر إشعار بوجود تحديث
4. جرب تحميل التحديث


═══════════════════════════════════════════════════════════════════
                          🎯 ملخص سريع
═══════════════════════════════════════════════════════════════════

1. حدث CURRENT_VERSION في الكود
2. شغل: .\publish-release.ps1 -Version "1.0.1"
3. نفذ أوامر Git
4. أنشئ Release على GitHub
5. ارفع ملف ZIP
6. حدث version.json (إذا لزم)
7. اختبر!


═══════════════════════════════════════════════════════════════════
                          📝 ملاحظات مهمة
═══════════════════════════════════════════════════════════════════

⚠️  تأكد من تحديث رابط GitHub في:
    - Services\UpdateService.cs (VERSION_URL)
    - version.json (DownloadUrl)
    - README.md (روابط الـ Releases)

⚠️  استبدل YOUR_USERNAME باسم المستخدم الحقيقي على GitHub

⚠️  رقم الإصدار يجب أن يكون بصيغة: X.Y.Z
    مثال: 1.0.1, 1.2.0, 2.0.0

⚠️  احتفظ بنسخة احتياطية قبل النشر!


═══════════════════════════════════════════════════════════════════
                          🆘 مشاكل شائعة
═══════════════════════════════════════════════════════════════════

❌ المشكلة: "tag already exists"
✅ الحل:
    git tag -d v1.0.1
    git push origin :refs/tags/v1.0.1
    git tag v1.0.1
    git push origin v1.0.1

❌ المشكلة: "404 Not Found" عند فحص التحديث
✅ الحل:
    - تأكد من رابط version.json صحيح
    - تأكد من الملف موجود في main branch
    - انتظر دقيقة (GitHub قد يحتاج وقت)

❌ المشكلة: فشل Build
✅ الحل:
    - تأكد من تثبيت .NET 8.0 SDK
    - نفذ: dotnet restore
    - جرب Build من Visual Studio
